# The Fourth Chair

A short text for the make.fun bounty "Make the AI judge feel curious". Every
morning a cafe sets three chairs outside, and this morning there are four —
with no one sitting in the extra chair, yet the coffee gone. One quiet scene,
one small mystery, and nothing more. The program writes the text to
`entry.txt` when it runs.
